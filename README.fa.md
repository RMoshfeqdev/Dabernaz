# Dabernaz Game Club | وب‌اپ باشگاه بازی

**پروژه شخصی رضا مشفق** · JavaScript · HTML/CSS · Node.js · PWA

Dabernaz یک وب‌اپلیکیشن فارسی و واکنش‌گرا با حال‌وهوای باشگاه بازی است. این پروژه چند صفحه و تعامل نمایشی شامل صفحه خانه، بازی‌ها، تورنمنت‌ها، دعوت دوستان، کیف پول آزمایشی، حساب کاربری، تنظیمات و پشتیبانی را ارائه می‌کند.

## قابلیت‌ها

- رابط فارسی و راست‌چین، مناسب موبایل و دسکتاپ
- ناوبری تک‌صفحه‌ای با تغییر محتوای بخش اصلی
- بازی‌های نمایشی Bingo، Poker، Slots و بازی حافظه
- ثبت‌نام نمایشی در تورنمنت‌ها
- تنظیمات کاربری و ویرایش نام نمایشی
- ذخیره وضعیت نمونه در `localStorage`
- قابلیت PWA با `manifest.webmanifest` و Service Worker برای کش فایل‌های ثابت
- وب‌سرور سبک Node.js بدون نیاز به پکیج خارجی

## فناوری‌ها

- HTML5، CSS3 و JavaScript خالص
- Node.js و ماژول‌های داخلی `http`، `fs` و `path`
- PWA، Web App Manifest و Service Worker
- `localStorage` برای نگهداری داده‌های نمایشی روی همان مرورگر

## اجرا

نیازمندی: Node.js نسخه 18 یا جدیدتر.

```bash
npm start
```

سپس `http://localhost:8080` را باز کنید. برای تغییر پورت:

```bash
PORT=8090 npm start
```

در Termux نیز پس از نصب Node.js، همین دستور `npm start` قابل استفاده است.

## محدودیت‌های نسخه نمایشی

- اطلاعات حساب، سکه‌ها و تراکنش‌ها فقط در `localStorage` همان مرورگر ذخیره می‌شوند.
- احراز هویت چندکاربره، پایگاه داده، بازی چندنفره/بلادرنگ، چت آنلاین و اتصال پشتیبانی به سرور وجود ندارد.
- پرداخت و برداشت وجه پیاده‌سازی نشده است و تمام سکه‌ها و جوایز مجازی و فاقد ارزش نقدی‌اند.
- این نسخه برای نمایش رابط کاربری و تعاملات فرانت‌اند است، نه سرویس بازی یا پرداخت واقعی.
